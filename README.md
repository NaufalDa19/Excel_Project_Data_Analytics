# Proyek Analitik Data Excel

Proyek ini dikerjakan untuk mengasah skill Excel dengan mengikuti course [Excel for Data Analytics](https://www.youtube.com/watch?v=pCJ15nGFgVg) oleh Luke Barousse.

## Salary Dashboard
Dashboard Excel yang menampilkan kisaran gaji data job berdasarkan posisi dan negara, dari data lowongan Data Science tahun 2023. Dashboard ini dibuat agar pencari kerja bisa membandingkan tawaran gaji dengan kondisi pasar dan menilai apakah gaji tersebut layak.
